⚙ Microsoft 365 Configuration

To connect your Microsoft 365 account, register an Azure AD app and enter your credentials below.

Setup Instructions:
1. Go to Azure Portal → App Registrations
2. Click "New registration" — name it "Farmboss Addison"
3. Set redirect URI to: http://localhost:8080/addison.html (and your production URL)
4. Under "Authentication", enable "Access tokens" and "ID tokens" under Implicit grant
5. Under "API permissions", add: Mail.Read (delegated)
6. Copy the Application (client) ID and Directory (tenant) ID above
